# Window samples (temporary)

Two clickable previews of the new WSL Control Panel window, so you can pick a
style. Both use **fake data**: nothing in WSL is started, changed or deleted.

| Double-click | What opens |
|---|---|
| `Try-Web-Sample.bat` | **Web-style** window: HTML/CSS shown by Edge in its own app window |
| `Try-Native-Sample.bat` | **Native** Windows (WPF) window, drawn by PowerShell itself |

Things to try in both: open a distro's desktop (Kali has no user yet, so it
asks you to create one first), download a distro, delete one (you must type its
name), and switch between the dark and light themes.

This folder is removed once a style is chosen.
